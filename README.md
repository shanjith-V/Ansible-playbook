# 🚀 Automated Nginx Deployment with Ansible & Passwordless SSH

This project automates the **installation and startup of Nginx** on a target AWS EC2 instance using **Ansible** from a host instance with **passwordless SSH authentication**.

## 📌 Project Overview
- **Host Machine**: Runs the Ansible playbook.  
- **Target Machine**: Receives the configuration and gets Nginx installed & started.  
- **Passwordless SSH**: Configured for secure and automated communication.  

## 🛠️ Tech Stack
- **Ansible** – Configuration management and automation  
- **AWS EC2** – Cloud computing instances  
- **Nginx** – Web server deployment  
- **SSH (Passwordless Authentication)** – Secure remote access  
- **YAML** – For writing Ansible playbooks
